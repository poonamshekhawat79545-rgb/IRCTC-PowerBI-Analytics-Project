# Base theme attribution

The native report includes Microsoft's CY24SU02 base theme from the [BCApps Projects report](https://github.com/microsoft/BCApps/blob/main/src/Apps/W1/PowerBIReports/Power%20BI%20Files/Projects%20app/Projects%20app.Report/StaticResources/SharedResources/BaseThemes/CY24SU02.json), retrieved 6 October 2026. Its data was preserved and serialized as readable JSON. The corresponding [Microsoft MIT license](MICROSOFT_BASE_THEME_LICENSE.txt) is included. The IRCTC custom theme is separately registered and uses the supplied six-color palette.
