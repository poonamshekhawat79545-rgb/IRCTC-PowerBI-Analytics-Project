What these fields can tell us

Recorded booking value

Sum of the source total field. This includes fare components and all selected statuses. Refunds, settlement and recognition rules are absent.

Distinct train numbers

The same train number is reused across names and routes. A distinct number count does not measure operated services.

Occupancy & delay

Values conflict within train-date groups. Treat averages as record-level descriptions, not operational performance.

Metric guide

Bookings. Row count equals distinct accepted booking IDs. Each row is a booking, which may contain several passengers.

Value. The sum of recorded total amounts across selected statuses. It is not recognized revenue or collected cash. ₹1 lakh = ₹1,00,000; ₹1 crore = ₹1,00,00,000.

Occupancy. Arithmetic mean of the supplied percentage per booking record. The data does not support a verified seat-weighted load factor.

Filters. All five filters combine. Charts, cards and insights recalculate from the selected records. Source reconciliation remains fixed.

Export. Downloads the selected accepted rows as CSV. Anonymous user keys preserve distinct-user analysis in the dashboard.

Scope. Synthetic data, supplied for a tutorial-inspired portfolio. No claim of affiliation with IRCTC. Definitions and reproducible calculations are included in the project.
